# Cuebook Build 375

Build 375 gives show pages a clearer overview and makes long-running productions easier to explore.

## Show overview

- Added a compact summary of performances, production periods, venues, people seen, and date span.
- Added a small “Most Seen” panel with direct links to the most frequently seen performers.

## Production periods

- Added production-period navigation to every show page.
- Selecting a production filters the cast grid, performance history, and cast-change summaries together.
- Incomplete legacy production metadata is grouped with the matching named production instead of creating duplicate periods.
- On phones, production periods use a compact swipeable rail.

## Cast changes

- Added a “Recent Cast Changes” section that compares each visit with the previous recorded performance.
- Highlighted changed cast-grid cells with a quiet tint and left-edge accent.
- Cast-change summaries collapse to a single column on smaller screens.

## Mobile cleanup

- Reflowed show export actions into a compact two-column grid instead of a clipped horizontal strip.
- Kept the show overview within the viewport without introducing page-level horizontal scrolling.

## Data integrity

- No attendance, cast, person, show, venue, credit, source, or Wicked records changed from Build 374.
