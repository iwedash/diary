# Cuebook Build 374

Build 374 is a focused desktop refresh with two user-requested behavior changes: primary show content now loads open, and the home page shows a rolling year of weekly activity.

## Interface changes

- Tightened the desktop content width, card spacing, heading scale, and overall vertical rhythm.
- Placed the home page's By Month and By Week views side by side on wide screens.
- Changed By Week to display the latest 52 weeks on both desktop and mobile.
- Compacted performance facts into a two-row desktop layout.
- Added a sticky desktop performance sidebar for notes, related performances, and program data.
- Reduced show-page hero height and made export actions less visually dominant.
- Tightened person-profile headers, facts, and table rows.
- Kept Cast, Ensemble, Covers, Company and Credits, and Songs open by default on performance pages.
- Kept Source / Archive collapsed as secondary reference material.

## Preserved from Build 373
